Ketersediaan & Standar Posisi Magang GM Academy

GM Academy membuka 6 posisi magang terfokus bagi siswa SMK dan mahasiswa perguruan tinggi di Kota Malang. Setiap posisi memiliki Key Performance Indicator (KPI) pembelajaran yang jelas, bimbingan langsung dari praktisi aktif agensi, serta penugasan studi kasus nyata. Kuota dibatasi maksimal 2–4 peserta per divisi pada setiap gelombang demi menjaga kualitas pendampingan 1-on-1 dan efektivitas transfer ilmu.

Kuota Aktif
Jalur: SMK (RPL/BDP) & Mahasiswa

SEO Specialist & Web Auditor

Mempelajari dan mempraktikkan optimasi mesin pencari organik melalui riset search intent kata kunci, perbaikan struktur internal linking, audit kecepatan, dan Google indexing.

Tugas & Tanggung Jawab:
  • Riset topik kata kunci komersial & transaksional.
  • Audit on-page, heading H1-H3, dan meta schema.
  • Monitoring data indeks Google Search Console.
Tools Dipelajari:
GSC GA4 Ahrefs/SEMrush Screaming Frog
Output: 20+ artikel terindeks Google Page 1 Daftar Divisi SEO
Kuota Aktif
Jalur: SMK (BDP/DKV) & Mahasiswa

Social Media Strategist

Mengelola kalender editorial media sosial, menyusun riset tren visual Reels/TikTok, menulis copywriting interaktif, dan menganalisis engagement audiens.

Tugas & Tanggung Jawab:
  • Perancangan kalender editorial Instagram & TikTok.
  • Copywriting carousel informatif & story engaging.
  • Analisis metrik reach, save, dan CTR mingguan.
Tools Dipelajari:
Meta Business Notion CapCut Pro Canva Pro
Output: 60+ konten feed & video terpublikasi Daftar Divisi Social Media
Kuota Aktif
Jalur: SMK & Mahasiswa (Komunikasi/Bahasa)

Content Writer & Copywriter

Memproduksi artikel edukatif berbasis framework AEO (Answer Engine Optimization), copywriting landing page penawaran, dan email newsletter bernilai konversi tinggi.

Tugas & Tanggung Jawab:
  • Penulisan artikel pilar berstruktur E-E-A-T.
  • Penyusunan format Direct Answer Box di awal artikel.
  • Copywriting headline & Call-to-Action interaktif.
Tools Dipelajari:
WordPress Google Docs Grammarly Claude/ChatGPT
Output: Pilar konten brand 15.000+ kata Daftar Divisi Content
Kuota Aktif
Jalur: SMK (RPL) & Mahasiswa (Informatika/SI)

Front-End Web Developer

Menerjemahkan wireframe/mockup Figma menjadi kode web responsif bersih, optimasi kecepatan Core Web Vitals, dan integrasi form konversi.

Tugas & Tanggung Jawab:
  • Slicing UI dari Figma ke HTML5/CSS3/Bootstrap 5.
  • Penerapan CSS variables & token desain konsisten.
  • Optimasi kecepatan rendering & mobile testing.
Tools Dipelajari:
HTML5/CSS3 JavaScript Bootstrap 5 Git / GitHub
Output: 1 Live Website Corporate Multi-Page Daftar Divisi Web Dev
Kuota Aktif
Jalur: SMK (DKV/MM) & Mahasiswa (Desain)

Graphic Designer & UI/UX

Merancang identitas visual, branding kit, micro-animation, banner iklan digital, dan wireframe antarmuka pengguna.

Tugas & Tanggung Jawab:
  • Pembuatan aset media sosial & infografis artikel.
  • Desain materi banner iklan digital A/B testing.
  • Perancangan wireframe komponen web di Figma.
Tools Dipelajari:
Figma Adobe Photoshop Illustrator Design Tokens
Output: Full UI Kit & 30+ Social Media Assets Daftar Divisi Desain
Kuota Aktif
Jalur: SMK (BDP) & Mahasiswa (Manajemen/Bisnis)

Digital Ads & Growth Support

Praktik setup kampanye Meta Ads & Google Ads, tracking pixel event konversi, A/B testing visual iklan, dan pembuatan dashboard report ROAS.

Tugas & Tanggung Jawab:
  • Setup funnel kampanye iklan Meta & Google.
  • Konfigurasi event konversi Pixel & Google Tag.
  • Penyusunan dashboard evaluasi ROAS & CTR.
Tools Dipelajari:
Meta Ads Google Ads Looker Studio Tag Manager
Output: Dashboard evaluasi performa kampanye Daftar Divisi Ads
